## 🌟 About The Project

**Study Meta App** is a student-focused productivity web application created to make studying more organized, focused and manageable.

The application provides useful study-management features such as **study planning, focus sessions, study tracking, notifications, profile management and theme customization** — all through a clean and interactive interface.

The project is built using **HTML, CSS and vanilla JavaScript**, making it lightweight and easy to run directly in a web browser without requiring a backend server.

---

## ✨ Features

### 📊 Study Dashboard

* View your study information in one place.
* Quickly access important study tools.
* Designed with a simple and student-friendly interface.

### ⏱️ Study Timer

* Start and manage focused study sessions.
* Configure timer settings.
* Track study time for different sessions.
* Save timer-related preferences.

### 📈 Study Tracking

* Maintain a study log.
* Track the amount of time spent studying.
* Organize study activity by date.
* Monitor your study consistency.

### 🔔 Notifications

* View study-related notifications.
* Notification panel for quick updates.
* Notification indicator for unread items.
* Clear notifications when required.

### 👤 Student Profile

* Customize your student profile.
* Change your display name.
* Select an avatar.
* Support for custom profile images.

### 🌙 Theme Support

* Switch between available interface themes.
* Theme preference is saved for future visits.

### 💾 Local Data Storage

The application uses browser **Local Storage** to preserve important information such as:

* Timer settings
* Study logs
* Notifications
* Profile information
* Theme preferences

This allows the app to retain data even after refreshing the page.

## 🚀 How to Run the Project

### Option 1 — Run Locally

1. Download or clone this repository.

```bash
git clone https://github.com/Syedhumera-svg/Study-Meta-App.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

---

### Option 2 — Run Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server** if you have the Live Server extension installed.

The application will open in your browser.
